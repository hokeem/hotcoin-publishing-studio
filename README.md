# Hotcoin Publishing Studio

Hotcoin 多语言内容制作、人工审核和 X / Publer 发布工作台。

线上工作台：https://hotcoin-publishing-studio.aitist-dev.chatgpt.site/

此仓库是 2026-11-23 线上版本的独立源码快照。公开版本已移除部署项目编号、Lark 内部表格地址和 Publer 工作区/账号编号，并改为服务端配置。不包含原仓库历史、运行密钥、数据库内容、发布台账或用户审核记录。上传源码不改变现有线上部署，也不会恢复已暂停的自动制作任务。

## 功能

- 每日资讯日报、今日关注、每日 Top 5、现货上新、永续合约上新、美股图文。
- 多语言图文制作、官方 Logo 获取与模板排版。
- Lark 表格读取、手动粘贴上新信息。
- 云端制作任务、两轮自主审核、人工审核意见和修订。
- Publer 分账号立即发布、定时发布、排期确认、撤回与再次发布。
- 发布记录、满 24 小时后采集累计统计，标注实际采集时间。
- 巴西时区与葡语内容策略。

## 项目结构

| 路径 | 内容 |
| --- | --- |
| `dist/` | 浏览器端源码和模板素材；这些文件是源文件，需要保留 |
| `worker/` | HTTP 后端、数据采集、模型调用与构建脚本 |
| `drizzle/` | 发布记录及巴西审核队列数据库迁移 |
| `tests/` | 离线审核、重试及排期确认测试，不会提交真实帖子 |
| `.env.example` | 服务端配置项，不包含真实凭据 |
| `.openai/hosting.example.json` | Sites 部署配置模板 |

自动制作任务表由 `studioInit` 初始化。

## 构建和测试

需要 Node.js 22.13 或更新版本。测试使用 Node 自带 SQLite，某些版本会打印实验功能提示。

```sh
npm test
npm run build
```

构建没有第三方 npm 依赖。输出 `dist/server/index.js`，内嵌前端及图片资源，并输出 `dist/.openai/hosting.json`。构建不会自动加载 `.env`；运行时必须由部署平台注入配置。

如部署到 Sites，复制 `.openai/hosting.example.json` 为 `.openai/hosting.json`，填入你自己的项目编号，再构建。未配置项目编号的示例文件仅供构建检查，不能直接发布。

后端需要 `DB`（D1 风格 SQLite）和 `BUCKET`（R2 风格对象存储）绑定。先应用 `drizzle` 目录中的 SQL 迁移。没有后端及存储绑定的静态预览只能查看界面，不能完整运行工作流。

## 运行配置

在部署平台的受保护运行环境中配置 `.env.example` 所列字段。Publer 账号编号必须对应各语言 X 账号，Lark 应用需要目标表格的只读权限；`LARK_BASE_URL` 填你自己的 Lark 租户域名。没有相应 API 密钥、访问权限或余额时，对应功能无法运行。

`STUDIO_AUTOMATION_PAUSED=true` 会阻止云端自动制作入口执行，已有稿件和手动制作保留。定时调度由托管平台单独管理，代码仓库本身不会创建任何定时任务。

公开源码不等于公开后台。生产环境必须为网页、`/api/*` 与 `/mcp` 配置身份认证及访问控制，才能使用包含真实发布凭据的后端。原站依赖 Sites 的私有访问控制；直接部署到公开 Worker 地址不会自动继承这层保护。

## 已知限制

人工点击与云端自动制作暂时使用不同渲染路径。人工路径的日报、Top 5、上新包含程序化排版；部分云端路径仍调用模型生成完整成图。因此不能保证两种方式质量一致。模型审核也可能误判。当前版本不承诺每天准点交付，自动制作保持暂停，发布需要人工操作。

模板中的样例是历史展示素材，不是实时行情。实际生产需要重新获取当天数据并核对有效性。
